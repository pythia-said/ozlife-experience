# OZLife media needed

The public showcase intentionally omits media that could not be captured strongly and honestly from the available fresh simulator state.

## Genuine app motion

- **Needed interaction:** A continuous Daily Hub → focus choice → one activity → completed progress or reflection → Garage or another meaningful reward-state flow.
- **Why current material is insufficient:** The existing GIF and MP4 are screenshot slideshows. The fresh External Release simulator has no prepared progress history, unlocked reward state, or completed activity sequence suitable for a concise public narrative.
- **Must be visible:** English UI, authentic navigation, a complete activity state, visible effect or completion, and a clean final reward or progression screen.
- **Recommended device and orientation:** iPhone 17 Pro, portrait, native simulator resolution; export a silent H.264 MP4 at 1080 × 1920 if the capture can be framed without cutting implemented UI.
- **Intended README position:** `See OZLife in motion`, after One day with OZLife.
- **User assistance required:** Yes. Provide or approve a publication-safe prepared app state with synthetic progress and unlocked content. No personal data or debug UI should be present.

- **Recommended device and orientation:** A supported portrait iPhone simulator where the top controls respect the safe area.
