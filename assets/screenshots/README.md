## Export guidance

- Use PNG in the sRGB colour space.
- Export all six images at the same pixel dimensions.
- Use a consistent **approximately 9:19.5 portrait aspect ratio**.
- Recommended dimensions: **1,290 × 2,796 pixels**.
- Keep device framing, corner treatment, and crop consistent across the set.
- Capture an English, production-configured presentation with developer controls hidden.
- Prefer synthetic or empty personal content and stable, publication-ready states.
- Provide meaningful alternative text when screenshots are added to the main README.
- Create optimized showcase derivatives and retain the approved originals outside the public repository when appropriate.

## Suggested README presentation

- Use a consistent displayed width across the complete sequence.
- Prefer two or three screenshots per row on wide layouts and preserve readable captions.
- Avoid rendering phone screenshots at their full source width.
- Keep captions as real Markdown text rather than embedding them into the image.
- Recheck layout on narrow screens after the actual files are added.

## Required publication review

Before each image is committed, verify that it contains none of the following:

- Real diary entries, reflection text, voice notes, health information, feedback, notifications, or email content
- Real names, account identifiers, device names, timestamps, or other personal metadata
- Developer menus, diagnostics, test states, hidden controls, internal build labels, or private QA information
- Internal URLs, infrastructure details, repository information, or configuration identifiers
- Secrets, API keys, tokens, certificates, signing details, team identifiers, or entitlement identifiers
- Unverified prices, unfinished purchase states, or claims of App Store availability
- Unapproved artwork, third-party material, recognisable likenesses, or media with unresolved rights

The repository owner should also confirm that all visible copy, branding, localization, and product states are appropriate for public release. Record any cropping, resizing, recompression, metadata removal, or other sanitization in the table above when an export is added.
