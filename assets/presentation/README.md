## Transformations

For each file:

- Two authentic crops from the mapped source are scaled proportionally with high-quality interpolation.
- The broader crop preserves screen context; the larger detail crop emphasizes the strongest interaction or content region.
- Crops are placed on a restrained, section-compatible gradient background with rounded clipping, a thin accent border, subtle depth, and low-opacity geometric accents.
- No fake UI, added marketing claim, glow, scanline, noise, reflection, heavy vignette, chromatic aberration, or screen distortion is present.
- The corresponding original screenshot was read only and was not modified, overwritten, renamed, resized, or recompressed.

The current README now uses complete authentic portrait captures at restrained widths. No presentation derivative in this folder is embedded there.
