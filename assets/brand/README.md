## Hero recommendation

- **Canvas:** 2,400 × 1,200 pixels
- **Format:** optimized PNG or high-quality JPEG in sRGB
- **Composition:** calm, restrained, and readable without relying on small interface text
- **Safe zone:** keep the primary subject, logo, and essential detail within the central 80% of the width and 70% of the height
- **Cropping:** leave enough quiet space for GitHub social-preview crops and narrower README layouts
- **File weight:** optimize for quick repository loading without introducing visible compression artefacts

The hero should create atmosphere and recognition without suggesting an unavailable product state.

## Light and dark GitHub themes

- Check the image against both light and dark page backgrounds.
- Avoid transparent edges that disappear into either theme.
- Keep sufficient contrast around the app icon and any wordmark.
- Do not place essential wording only inside the image; retain the product name and claim as real README text.
- Prefer a subtle border or self-contained background when an asset has pale or very dark outer edges.

## Suggested alternative text

Update the wording after inspecting the actual export.

## Publication and rights review

Before adding any app icon, hero artwork, social card, launch artwork, motif, avatar, or other brand material, the repository owner should confirm:

- Copyright ownership and any third-party licence terms
- Generative-image provenance and permitted commercial use
- Consent for identifiable people, performers, voices, or likenesses
- Potential trademark conflicts
- Approval of the exact exported file for public redistribution
- Removal of embedded personal or production metadata where appropriate
- Sufficient resolution, appropriate cropping, and accessible alternative text
- Whether localization-specific artwork is suitable for the intended context

Only approved, publication-ready exports should be placed here. Do not copy original asset catalogues, working files, or media from a private repository.
