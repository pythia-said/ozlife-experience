# Contributing

OZLife is a proprietary product. This public showcase is not an open-source project, and code contributions are not accepted.

Helpful public feedback is welcome for:

- Documentation errors
- Unclear wording
- Broken internal documentation links
- General product questions

Please submit these through [GitHub Issues](../../issues). Do not include source code, confidential material, personal data, private product information, or sensitive security details.

By participating, you agree to respect the proprietary terms in [LICENSE](LICENSE). Opening an issue does not grant permission to use, modify, or redistribute any part of OZLife.
